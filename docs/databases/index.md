Эксплуатация СУБД: резервное копирование, обслуживание, диагностика, типовые операции.

## Что важно в любой СУБД

| Тема | Почему критично |
|---|---|
| **Бэкапы + проверка восстановления** | без этого всё остальное бессмысленно |
| **Модель восстановления** | определяет, можно ли восстановиться на момент времени |
| **Индексы** | скорость чтения против скорости записи |
| **Статистика** | устаревшая статистика = плохие планы запросов |
| **Свободное место** | журнал транзакций любит расти неожиданно |
| **Права** | принцип наименьших привилегий |

## Универсальный чек-лист «база тормозит»

1. Посмотреть активные сеансы и их ожидания.
2. Найти топ запросов по времени и по чтению.
3. Проверить план самого тяжёлого запроса.
4. Проверить, свежая ли статистика.
5. Проверить свободное место и рост журнала.
6. Проверить, нет ли блокировок и deadlock'ов.
