## Шпаргалка по адресации

| Диапазон | Маска | Назначение |
|---|---|---|
| `10.0.0.0` – `10.255.255.255` | `10.0.0.0/8` | частная сеть класса A |
| `172.16.0.0` – `172.31.255.255` | `172.16.0.0/12` | частная сеть класса B |
| `192.168.0.0` – `192.168.255.255` | `192.168.0.0/16` | частная сеть класса C |
| `169.254.0.0/16` | — | APIPA, адрес не получен по DHCP |
| `127.0.0.0/8` | — | loopback |

## Быстрые проверки

```bash
ping 8.8.8.8          # доступность по IP
ping ya.ru            # работает ли DNS
tracert ya.ru         # маршрут (Windows)
traceroute ya.ru      # маршрут (Linux)
ipconfig /all         # адрес, шлюз, DNS (Windows)
ip a && ip r          # адрес и маршруты (Linux)
```
