# Linux

Ежедневные операции администратора: файлы, права, процессы, службы, сеть, журналы.

## Страницы раздела

| Страница | О чём |

| [Базовые команды](basic-commands.md) | файлы, поиск, права, процессы, сеть |
| [systemd](systemd.md) | службы, юниты, journalctl, таймеры |

## Мини-шпаргалка

```bash
uname -a                # ядро и архитектура
cat /etc/os-release     # версия дистрибутива
df -h                   # место на дисках
free -h                 # память
uptime                  # нагрузка
ss -tulpn               # открытые порты
journalctl -xe          # последние ошибки
```

## Что где лежит

| Путь | Содержимое |
|---|---|
| `/etc` | конфигурация |
| `/var/log` | журналы |
| `/var/lib` | данные служб |
| `/home` | домашние каталоги |
| `/opt` | стороннее ПО |
| `/etc/systemd/system` | свои юниты |
| `/proc`, `/sys` | виртуальные ФС ядра |

!!! tip "Принцип"
    В Linux почти всё — файл. Настройка — правка файла в `/etc`, применение — перезапуск службы.
    Прежде чем менять конфиг, сохраните копию: `cp file file.bak-$(date +%F)`.
