## Из чего состоит серверная 1С

| Компонент | Что делает |
|---|---|
| **1С:Предприятие (клиент)** | тонкий, толстый, веб-клиент |
| **Сервер 1С** (`srv1cv83`) | исполняет серверный код, обслуживает сеансы |
| **Кластер серверов** | центральный и рабочие серверы, менеджер кластера |
| **СУБД** | файловая база или MS SQL / PostgreSQL / Oracle |
| **Веб-сервер** (IIS, Apache) | публикация веб-клиента и HTTP-сервисов |

## Полезные утилиты

- `1cv8s.exe` — администрирование сервера (кластеры, сеансы, регламентные задания);
- `1cv8.exe DESIGNER` / `CONFIG` / `ENTERPRISE` — режимы запуска;
- `ras.exe` + `rac.exe` — удалённое администрирование кластера через сервис RAS;
- `ibsrvr.exe` — служба сервера 1С.

## Типовые порты

| Порт | Назначение |
|---|---|
| 1540 | менеджер кластера |
| 1541 | рабочий процесс |
| 1545 | сервис RAS (администрирование) |
| 1560–1591 | динамический диапазон рабочих процессов |
| 80/443 | публикация веб-клиента |

!!! note "Правило"
    Всё, что делается в интерфейсе администрирования сервера 1С, можно сделать
    скриптом через `rac` — это удобно для автоматизации и для проверки «а как было до».
