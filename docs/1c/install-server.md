# Установка сервера 1С

## Подготовка

1. Сервер под управлением Windows Server или Linux (для 1С 8.3.21+ Linux поддерживается официально).
2. Статический IP, имя в DNS, синхронизация времени.
3. Достаточно RAM: для 50–100 пользователей обычно от 16 ГБ, плюс запас под СУБД.
4. Отдельный диск под журналы и временные файлы.
5. Учётная запись службы с правами, но **без** прав локального администратора на постоянной основе.

## Порядок установки (Windows)

1. Запустить дистрибутив `setup.exe` от имени администратора.
2. Выбрать компоненты:
   - **1С:Предприятие** — сервер;
   - **Сервер 1С:Предприятие** — обязательный компонент;
   - **Расширение работы с файлами** — если нужны файловые операции на сервере;
   - **Модули расширения веб-сервера** — для публикации на IIS.
3. Указать учётную запись службы (доменную, с правом входа как служба).
4. Завершить установку, проверить службу:

```powershell
Get-Service "1C:Enterprise 8.3 Server Agent*" | Format-Table Name, Status, StartType
```

## Кластер

После установки на сервере автоматически создаётся **кластер** с центральным сервером
и одним рабочим процессом. Управление — через `1cv8s.exe` (оснастка администрирования
серверов 1С) или через `rac`:

```powershell
# подключиться к локальному кластеру
rac.exe --host localhost --port 1545 --cluster

# список информационных баз кластера
rac.exe cluster list --cluster=<uuid>

# список сеансов
rac.exe session list --cluster=<uuid>
```

## Публикация на IIS

```powershell
# из каталога с утилитой webinst
webinst.exe -iis -d "C:\inetpub\wwwroot\base1" -sec-usr "USR1CV8" -sec-pwd "пароль" `
  -conf "C:\Program Files\1cv8\conf" -wsdir base1 `
  -connstr "Srvr=server1;Ref=base1;"
```

Проверка: `http://server1/base1` открывает форму входа.

## Грабли

!!! warning "Частое"
    - **Служба не стартует** — проверьте права учётной записи и права на каталог `C:\Program Files\1cv8`.
    - **Порт 1540/1541 занят** — `netstat -ano | findstr 1540`, освободите или смените диапазон в настройках кластера.
    - **Не открывается веб-клиент** — модули расширения веб-сервера не установлены или не совпадают с разрядностью IIS.
    - **Медленно** — смотрите журналы технологического журнала (`logcfg.xml`) и статистику SQL-сервера, а не только 1С.
    - После обновления платформы нужно **переустановить** сервер и заново опубликовать базы.
